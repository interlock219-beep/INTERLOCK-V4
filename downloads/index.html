Install for VS Code

The Interlock VS Code extension wraps the same recovery engine the terminal uses. Its source is in this repository; nothing is published.

  • No Visual Studio Marketplace listing exists, so there is no button or link here.
  • No .vsix artifact is published or distributed; a local build is yours to make.
  • The extension installs and verifies the engine it needs (Windows x64 bundles a pinned runtime).
Installable today

Install for the terminal

The intentlock Python package installs from a repository checkout into a virtual environment.

  • Not published to PyPI yet — installation is from source (or a locally built wheel).
  • Requires Python 3.11–3.14 (3.11.9 verified); no Docker, root, or network at run time.
git clone <INTERLOCK REPOSITORY URL> interlock
cd interlock
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
pip install -e ".[dev,security]"

The full walkthrough — including the evidence trail and post-install checks — is in README.md (Quickstart) and docs/operations/BETA_FIRST_RUN.md of the repository.
